## 本地与发布环境

业务源码使用同一份。开发目录保留本机后端连接及本地预览入口；打包时关闭这些开发入口并连接服务器。差异仅涉及 `app.js`、`pages/register/register.wxml`、`project.config.json`，由仓库内脚本明确生成，不再靠手工编辑发布副本。

在仓库根目录执行以下命令生成小程序生产源码目录（输出目录必须在仓库外，且尚不存在）：

```sh
python3 scripts/package_miniapp.py --output /absolute/path/to/new/WeChatMiniApp
```

该目录可以直接用开发者工具打开并上传。默认启动页仍为 `pages/browse/browse`，允许未登录浏览课程和上架资料；用户主动选择报名、购买或登录时再授权手机号。登录页隐私选项默认未勾选，打开指引不会自动同意。

如果生成直接到登录页的小程序码，页面路径使用 `pages/register/register`；这不改变默认启动页。

数据库数据、服务器微信密钥、数据库密码、运行环境及私有上传配置均不进入 Git。该次代码对齐不修改数据库，也不重新提交微信审核。
