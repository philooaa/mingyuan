# 本地服务启动说明

## 日常启动

双击项目根目录的 `启动本地服务.cmd`，在窗口提示时输入 MySQL 的 root 密码并按回车。输入过程不会显示密码。等待窗口显示四项服务均 ready，再访问：

- 管理前端：http://localhost:8081/
- 后端：http://localhost:8080/
- MySQL：127.0.0.1:3306，数据库 `mingyuaneduminiapp`
- Redis：127.0.0.1:6379

已经运行的服务会进行检查，不会重复启动。窗口中的提示信息和日志使用英文；按任意键关闭启动窗口不会主动关闭后台服务。

## 脚本做什么

依次检查或启动 MySQL、Redis、后端和管理前端；检查数据库能否用 root 登录且目标库存在，检查 Redis 的 PING，以及前后端 HTTP 响应。新启动的后端使用 `druid,local` 配置并仅监听本机，供开发者工具使用模拟身份预览；该配置不可用于生产环境。如果后端已经在运行，脚本不会更改它的配置。日志位于项目内 `logs/local-start/`，每次启动相应服务时会覆盖该服务上次的日志。脚本不会导入数据库或执行迁移。

MySQL 和 Redis 使用以下现有安装及其数据配置：

- MySQL：`D:\BaiduNetdiskDownload\mysql\01MySQL\mysql-8.0.31-winx64`
- Redis：`D:\BaiduNetdiskDownload\ruoyi_envir`

如果安装目录变化，可在 PowerShell 中使用参数指定：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start_local.ps1 -MySqlHome '新的MySQL目录' -RedisHome '新的Redis目录'
```

脚本需要 Java、Node.js 在 PATH 中，前端已安装依赖。也可以通过 `-Java 'java.exe的完整路径'` 指定 Java；当前项目要求 Java 17 或更高版本。若前端依赖缺失，在 `RuoYi-Vue-master\ruoyi-ui` 目录运行 `npm install`。

## 后端代码更新

启动脚本会使用 `RuoYi-Vue-master\target` 下最近生成的完整后端程序包，**不会自动编译最新源码**。修改后端源码后，需要先构建，再停止旧后端并重新启动；仅重复运行启动脚本会保留已运行的后端进程。构建可使用 `scripts\build_backend_local.ps1`，该脚本需要按本机实际位置配置 Maven、Java 和 Maven settings。构建完成后再运行启动脚本。前端开发服务器会自动处理大多数前端源码更改。

## 常见问题

- MySQL 启动失败：检查上述安装目录、数据目录的读写权限及 `logs/local-start/mysql.err.log`。不要初始化或覆盖现有数据目录。
- 数据库登录失败：确认输入的 root 密码和目标数据库；脚本不保存密码到文件。也可在当前 PowerShell 会话中先设置 `MYSQL_PASSWORD` 环境变量，脚本将直接使用它。
- 提示数据库结构不完整：检查排课规则字段和规则表、考勤临时学生表是否已迁移。脚本会提前报出迁移文件位置；备份并核对后再执行相应迁移，避免启动成功后页面才提示“服务暂时不可用”。
- Redis 启动失败：检查配置、数据目录权限及 `redis.out.log`、`redis.err.log`。
- 端口被占用：先确认占用端口的进程；脚本不会自动结束任何进程。HTTP 检查只能证明端口上有响应，不能完全确定进程身份。
- 前端首次编译较慢：默认等待 120 秒，可用 `-TimeoutSeconds 300` 延长等待时间。若构建报错，查看 `frontend.out.log` 和 `frontend.err.log`。
- 微信小程序需要另外通过微信开发者工具打开 `WeChatMiniApp`，本脚本启动的是管理前端和后端。
