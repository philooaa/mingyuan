# 小程序收费选券入口

## 使用位置

教务／管理员进入“收费财务”→打开普通课程账单→完成核价→在“第二步：登记实际收款”中选择优惠券。默认不使用券，可用券由后端按家长、课程、金额和有效期筛选。

页面显示后端最新报价：原价、优惠、最终应收；确认线下实际收款后再登记。试算不会使用或锁定优惠券，正式登记及收款确认沿用原后端流程。

一对一课包在购买页面选券，收款时只展示锁定报价，不允许换券。结果未知的收款登记沿用原券、金额、版本与请求标识重试，不能另选优惠券生成新请求。

## 防误操作

- 报价未完成、失败或无效时不能登记收款；允许取消失效券后重新试算。
- 以服务端报价的优惠券编号、应收金额及账单版本提交，不在手机端自行扣减。
- 优惠后应收为零时使用费用减免渠道，不要求付款截图。
- 同一账号返回页面时保留选券并重新试算；旧请求不能覆盖新报价或已离开的页面。
- 不改后端、数据库及既有收款记录。新增入口需重新预览或更新小程序包。

## 验证

收费、课包及优惠券管理定向测试共 64 项通过；WXML 与 WXSS 通过微信开发者工具附带编译器检查。未在服务器登记真实收款或使用真实优惠券，手机完整流程需使用新预览包核验。
