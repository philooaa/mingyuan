# 请假课时表实施计划

经确认：只统计已终审请假（sign_status=3），不计录播或历史未到课。管理员、业务管理员和教务可查询；教师和家长无权访问。仅本地开发。用户后续明确不需要 Excel 导出，仅提供在线查看。

1. 新增只读请假报表服务及隔离 MySQL 回归测试。以学生稳定 ID 和课程汇总，保留讲次、日期和联系方式；重复身份课次标为待核对。仅抵扣明确关联原课次、且唯一有效终审到课的调课记录，禁止按姓名或到课数量猜测抵扣。
2. 增加在线查询接口；可选关键词、年份、季度、教师、年级、日期、处理状态，支持分页；结果过多时提示缩小范围。
3. 网页学生出勤增加请假课时表标签，小程序增加独立页面和入口，均支持筛选、在线查看讲次；显示请假、已关联补课、待处理及待核对数量。没有明确退款关联时不自动扣减、不自动退款。
4. 执行隔离数据库测试、前端交互测试、编译和权限校验，启动本地后端并验证实际接口；代码审查后交付本地入口，不自行部署。
