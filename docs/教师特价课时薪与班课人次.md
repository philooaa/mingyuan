# 教师特价课时薪与班课人次

小程序入口：管理员 → 教师管理 → 编辑标准。网页入口：教师薪资标准 → 编辑。

- “初中班课”更名为“初高中班课”，继续使用原来的薪资字段。
- 排课班型新增启用选项“特价课”。班课且班型为“特价课”时，使用教师独立设置的特价课时薪，替代对应学段班课时薪；一对一仍使用原有一对一时薪。
- 特价课工资 = 特价课小时数 × 特价课时薪，单独展示节数、小时数与金额，工资合计只加一次。时薪初始为 0，使用前应设置对应教师标准。
- 每节课时数支持小数，沿用数据库现有的一位小数精度。
- “班课人次提成”按月统计数量：每位学生每上一节班课计 1 人次，同一学生上不同课或不同日期分别累计；包括特价课、试听到课、调课到课，排除一对一、缺勤、请假和录播。沿用工资统计的终审通过口径。
- 薪资标准新增“每人次单价（元/人次）”，支持0元及正数，最多两位小数。总提成 = 当月班课人次 × 每人次单价；默认单价为0，设置后保存薪资标准。页面可预览当前输入的总提成，生成结算时以已保存的单价及人次为准。
- 管理员可按教师和月份保存非负整数人次，或点击“恢复自动统计”；修改人次不会改变签到记录。手动保存后以手动值为准，自动统计值仍同步展示。单价按教师保存，人次按教师和月份保存，两者分别保存。
- 班课人次提成加入工资应发合计，与原有固定金额提成分别展示。应发 = 底薪 + 课时费 + 固定提成 + 班课人次提成。
- 结算时保存人次、单价、提成金额快照；已确认结算沿用原快照，修改人次或单价不会自动重算历史工资。尚未确认的结算可通过原有“生成/更新结算单”流程更新。

## 数据迁移

上线前备份目标库，先确认已执行 `database/migrations/20261125_salary_special_attendance.sql`，再执行新增的 `database/migrations/20261125_salary_attendance_commission.sql`，随后同步部署后端、网页及小程序。

特价课迁移新增特价课时薪、工资分类快照字段、人次调整表和班型字典选项；新增人次提成迁移只补充薪资标准的人次单价，以及结算单的人次、单价、提成快照字段。两份迁移均可重复执行，不会重算历史工资、改写报名或考勤；历史记录新增字段默认0。
