## 首次排查结果（最终写入开关修改前）

- 110 次本地接口检查全部返回业务码 200，覆盖公开页面、管理员、教务、家长、教师，以及部分有实际课程和报名记录的账号。覆盖排课列表与详情、课表网格和日历、排课规则列表、价格、教室安排、报名、学费、薪资预览、考勤、教师待办和学习资料等读取接口。
- 小程序现有测试 498 项全部通过。
- 后端选定测试 56 项全部通过，无跳过。包括 `ScheduleRuleMysqlTest`、`ScheduleCrudTest`、`ScheduleDateRuleTest`、`CourseLessonCountTest`、`TimetableTeacherMatchingTest`。规则新增、编辑、并发版本校验及重复迁移在独立临时数据库中验证，测试完成后删除该临时库。
- 首次排查时已确认被测构建与当时的 `ruoyi-system`、`ruoyi-admin`、`ruoyi-framework` 源码和测试文件一致。此结论不适用于之后加入生产写入开关的最终源码。
- 管理员和教务的路由数据均包含 `system/scheduleRule/index`，对应网页组件存在，前端已有编译成功记录。
- 扫描运行时 SQL 的表引用，没有发现其他缺失业务表；扫描迁移中的显式单列 ADD COLUMN，没有发现未补齐的列。两个历史迁移中引用的旧表名没有出现在当前运行时 SQL 中，未据此创建旧表。

首轮探测中，缺参数的课表网格请求已补全参数重测；教师访问仅面向管理人员的排课维护接口返回 403，属于现有权限限制，不作为数据库错误。
