# 小程序课程排课与教室分配对接

## 本次功能

- 小程序首页的教务、管理员工作台增加“排课管理”，可新增和修改课程。
- 排课选择校区、教师、年级、学科、学期、期次、时段、日期、班型、授课形式、单价和招生状态；不选择教室。
- 支持班课及一对一。一对一沿用单日、固定两小时时段、教师冲突校验。
- 家长可以在教室尚未分配时报名；原有招生状态、报名上限、重复报名及教师时间冲突规则继续生效。
- 账单初始化及校区展示支持尚未分配教室的课程。
- 纯教师账号不能新增、修改或发布排课：移除教师页面入口，旧页面地址显示说明，旧接口及共享服务也限制写入。教师仍可查看本人课程、处理报名和记录课次。
- 同时拥有教务或管理员身份的教师账号可在对应工作台排课。业务管理员遵循既有管理员身份判断。

## 数据库与升级顺序

新增 `edu_course_schedule.campus_name`，`classroom_id` 可为空。校区不是临时教室，不创建占位教室记录。

1. 备份数据库，停止后端写入。
2. 执行 `database/migrations/20261028_schedule_campus_first.sql`。
3. 部署本次后端并启动，随后上传新版小程序体验版。

迁移可以重复执行：补齐字段，必要时解除教室必填限制，并按原有教室补齐旧课程校区；不删除课程、报名或财务记录，不自动授权角色。

此前交付的 `mingyuan_test_full_20261028.sql` 导出早于本次改动。协作者导入该文件后，也需要执行本次迁移。旧库原有的一对一、报名上限、财务等迁移仍是前置条件，本脚本只升级本次校区功能。

## 小程序接口

仅教务、超级管理员及业务管理员可调用 `/miniapp/staff/schedule`：

| 方法与路径 | 用途 |
| --- | --- |
| GET `/options` | 教师、校区及排课字典；校区来自启用教室所属校区 |
| GET `/list` | 分页课程列表，支持课程名称搜索 |
| GET `/{id}` | 课程详情 |
| POST 基础路径 | 新增课程，只传 `campusName`，不传 `classroomId` |
| PUT 基础路径 | 修改课程，已有教室不会被清空，本接口不负责更换教室 |
| DELETE `/{id}` | 沿用既有删除保护；本次小程序不提供删除按钮 |

数据库仍使用原课程、报名和财务表，没有另建小程序专用课程数据。空日期班课为待排日期，不猜测实际授课日；一对一必须提供有效日期。

## 后续教室分配功能约定

协作者单独实现分配入口及接口，本次不提供教室选择。

- 以 `schedule_id` 定位课程，`campus_name` 表示已经选择的校区，`classroom_id IS NULL` 表示待分配。
- 分配时核对教室启用状态及所属校区；不要清空报名记录或重建课程。
- 家长可能已经报名，因此不能直接依赖普通“修改课程”接口：该接口保留有效报名和历史保护，会拒绝已报名课程的普通编辑。应实现仅变更教室的受限操作，保留教师、日期、费用和报名信息，并处理资源锁、教室冲突和操作记录。
- 已有教室的课程不通过本次小程序排课表单改校区；后续分配功能如需跨校区，须明确处理关联信息及历史。
- 教师不能通过教室分配功能绕过排课权限。

## 登录与本地联调

- 登录页仅提供微信手机号授权，登录前不选择角色；首页右上角菜单仅显示当前账号已有角色，切换时保留同一个账号和登录会话。
- 开发者工具连接本机 `http://127.0.0.1:8080`，手机预览及体验版连接既有服务器域名。本机后端必须启动。
- 如需在本地识别真实手机号，应在代码仓库外的私有配置中设置 `wechat.miniapp.mock-enabled: false`，并通过环境变量 `WECHAT_APPID`、`WECHAT_SECRET` 配置当前小程序的微信凭据。`local` 配置默认启用模拟授权，默认测试手机号只对应测试家长，不会自动获得其他角色。
- 修改授权配置并重启后端后，需退出旧测试账号，再重新进行微信手机号授权。不得通过给默认家长加角色来代替真实手机号匹配。
- 数据库备份、微信密钥和本机运行配置不包含在此 PR。

## 与课表日历、导出和教室分配 PR 的合并说明

教务与管理员工作台同时保留“排课管理”和“教室分配”。教师不增加课程发布或教室分配权限；手机号登录及右上角身份菜单保持原有流程。

部署前备份并暂停后端写入，按顺序执行以下可重复升级脚本，再部署合并后的后端、管理网页及小程序：

2. `20261028_schedule_adjustment_date_level.sql`：补齐日期级调课字段、按学期和期次区分同一天的记录，并补齐历史记录所属期次；保留历史调课明细。

首次分配也必须匹配课程原先选择的校区；分配后同步保留模板校区。首次分配前的历史日期保持“无教室”，不回填成后来分配的教室。未分配卡片显示课程校区，分配过程不改报名和收费记录。
